#PENDLE Market 



## Usage : Separating Token Functions with Pendle

Depositing an asset in a Pendle market allows you to separate its two fundamental functions:

- The principal value: the original amount you deposit.
- The yield: the interest or rewards generated over time.

This is achieved by splitting your asset into two new tokens:

- PT (Principal Token): entitles the holder to reclaim the original principal at maturity.
- YT (Yield Token): entitles the holder to all the yield generated by the principal until expiration.
- SY (Standardized Yield Token): acts as a wrapper for yield-bearing assets, enabling Pendle to split the asset into PT and YT, and serving as the base asset within the market.

Each of these tokens can be traded independently on secondary markets.


 ## main methods

| Function                                    | Description                                                                    | Main Use Case                                           |
| ------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------- |
| `isExpired()`                               | Returns `true` if the market has reached its expiry date.                      | Check if maturity has been reached; PT can be redeemed. |
| `expiry()`                                  | Returns the UNIX timestamp of the market’s expiry/maturity.                    | Know exactly when the market/position matures.          |
| `activeBalance(address)`                    | Returns the amount of liquidity currently active for a given address.          | View how much liquidity a user is providing.            |
| `readTokens()`                              | Returns the addresses of the SY, PT, and YT tokens associated with the market. | For integrations; identify the market’s core tokens.    |
| `swapExactPtForSy(address, uint256, bytes)` | Swaps an exact amount of PT tokens for SY tokens.                              | Sell PT to receive the underlying asset (SY).           |
